# 百度网盘发布清单

## 最终打包后上传

1. `RBCM-Edge-Checkpoints`
   - BIPED、严格 MultiCue 和严格 NYUDv2 的精选 checkpoint；
   - 冻结的验证集候选、配置、协议清单和 SHA-256 清单；
   - 当前未压缩大小为 425,987,732 字节，约 0.397 GiB；
   - 该包是项目自产资产，优先级最高。

2. `RBCM-Edge-Datasets`
   - 完整的 `edge_data/official_rbcm` 和 `edge_data/official_repro`；
   - 划分文件、处理后 GT、文件索引和协议哈希；
   - 当前未压缩大小为 17,236,266,110 字节，约 16.05 GiB；
   - 只有在逐项确认上游数据集允许再分发后，才能上传完整图像和 GT。若不允许，
     只发布划分/协议小包，并提供官方下载地址和数据准备命令。

3. `RBCM-Edge-MEA-Data`
   - 最终 MEA 输入和逐文件 SHA-256 清单；
   - 当前未压缩大小为 8,858,482,461 字节，约 8.25 GiB；
   - 只有在伦理、知情同意、机构和来源数据共享要求允许后才能上传，否则采用受控
     访问或按申请提供。

## 放在 GitHub，不放网盘

- 公开 `release` 源码分支；
- 模型与数据准备、训练、推理、评估、绘图和 MEA 脚本；
- 严格划分列表及哈希；
- 小型得分表和公开协议清单；
- `REPRODUCE.md`、环境文件和下载说明。

## 不直接再分发

- 未明确获得上游许可的外部模型权重；
- 私有仓库历史、废弃 checkpoint、调试输出、原始服务器 run 和历史模型版本；
- 未获再分发授权的原始数据集或 MEA 记录。

外部模型只发布名称、上游链接、上游 checkpoint 哈希、适配命令和统一评估命令。
每个网盘压缩包制作完成后，重新计算压缩包级 SHA-256，并把链接、提取码、字节数和
哈希填入 `DOWNLOADS.md`。
