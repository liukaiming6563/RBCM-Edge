# Strict-protocol H-RBCM results

This directory is generated by `scripts/analysis/build_strict_protocol_tables.py` and contains only independent paper-facing protocols.

## Primary same-domain findings

- BIPED: three fixed 170/30/50 splits. Relative to the strongest matched control per metric, H-RBCM changes ODS/OIS/AP by +0.78/+0.77/+0.48 percentage points.
- MultiCue: strict 68-source training, 12-source validation, and 20-source one-time held-out testing. H-RBCM improves ODS/OIS by +2.22/+1.76 points and changes AP by -0.92 points. This supports an F-score benefit with an explicitly reported AP trade-off.
- NYUDv2: strict zero-overlap 381/414/654 split. H-RBCM improves ODS/OIS/AP by +0.82/+0.74/+0.94 points.

## Strict NYUDv2 external comparison

Under the shared target evaluator, same-domain NYUDv2 H-RBCM scores 0.84291/0.85342/0.87266 versus 0.83224/0.84163/0.86016 for the released PiDiNet NYUDv2 RGB checkpoint. The changes are +1.07/+1.18/+1.25 percentage points.

Cross-domain external performance is mixed: all three metrics improve on BIPED; ODS/OIS improve on UDED with a small AP decrease; MultiCue and BSDS500 are lower. The defensible claim is strict same-domain NYUDv2 superiority and selected transfer advantages, not universal superiority over PiDiNet.

## Files

- `same_domain_strict.csv`: four-mode same-domain results for the three primary independent protocols.
- `main_vs_strongest_control.csv`: main-model change relative to the strongest matched control for each metric.
- `nyudv2_five_target_ablation.csv`: frozen strict-NYUDv2 checkpoint/candidate matrix across five targets.
- `nyudv2_vs_pidinet.csv`: source-matched NYUDv2 comparison under the shared target evaluator.
